# Cara memasang kode ini
1. Salin isi folder `app/`, `components/`, dan `assets/images/` ke proyek `Profile-Tim-` (timpa `app/index.tsx`).
2. Jalankan `npx expo start`, scan QR dengan Expo Go.
3. Ganti foto placeholder di `assets/images/` dengan foto asli (nama file tetap sama).
4. Tiap anggota hanya mengedit file `components/members/ProfilNAMA.tsx` bagian A.
